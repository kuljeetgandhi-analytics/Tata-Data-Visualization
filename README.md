# Tata Data Visualization – Online Retail Analytics Dashboard

## Project Overview
A Power BI data visualization project completed as part of the **Tata Data Visualization Job Simulation on Forage**.

## Objectives
- Analyze monthly revenue trends.
- Compare country-level revenue and product quality.
- Identify the top 10 customers by revenue.
- Explore product demand across countries.
- Present retail data insights through clear visualizations.

## Tools & Skills
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Business Intelligence
- KPI Analysis
- Reporting

## Dashboard Highlights
- Q1: Monthly Revenue
- Q2: Country Revenue and Quality
- Q3: Top 10 Customers by Revenue
- Q4: Product Demand by Country

## How to View
1. Download the `.pbix` file from this repository.
2. Open it in Microsoft Power BI Desktop.
3. Navigate through the report pages and interact with the visuals.

> GitHub cannot display interactive Power BI reports directly. Use Power BI Desktop to open the `.pbix` file.
